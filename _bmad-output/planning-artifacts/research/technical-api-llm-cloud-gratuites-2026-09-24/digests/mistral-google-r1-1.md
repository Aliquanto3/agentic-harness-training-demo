# Digest — API LLM cloud gratuites : Mistral AI vs Google Gemini (2026-09-24)

## Candidat 1 : Mistral AI — La Plateforme, offre gratuite « Experiment »

- Mistral La Plateforme propose un tier gratuit « Experiment » destiné à l'expérimentation, l'évaluation et le prototypage, distinct des tiers payants « Scale » (pay-as-you-go) et « Custom » (Enterprise) — source : Usage and limits (Mistral Docs, non daté, consulté 2026-09-24) https://docs.mistral.ai/admin/user-management-finops/tier — confiance : moyenne — classe : quota
- Plusieurs agrégateurs convergent sur un plafond historique d'environ 1 milliard de tokens/mois pour le tier Experiment, mais Mistral ne publie plus de chiffres RPM/TPM exacts publiquement ; il faut consulter Admin Console → Limits — source : Mistral La Plateforme free tier (BenchLM.ai, non daté, consulté 2026-09-24) https://benchlm.ai/free-tier/mistral — confiance : basse — classe : quota
- Le changelog officiel Mistral Docs (entrées janvier à août 2026) ne mentionne aucune suppression ni réduction du tier Experiment de l'API en 2026 ; les seules entrées concernent des sorties de modèles et des mises à jour de paramètres API — source : Changelog (Mistral Docs, mis à jour en continu, consulté 2026-09-24) https://docs.mistral.ai/resources/changelogs — confiance : haute — classe : stabilité
- Des agrégateurs affirment qu'en septembre 2026 le « free tier » Mistral a changé, passant d'une allocation API (2 RPM, 1 Md tokens/mois) à des messages limités dans Vibe/Le Chat plus 10 $/mois de crédits API vendus séparément — mais cette affirmation semble concerner le plan gratuit de Le Chat (Vibe/Studio, interface consumer), pas nécessairement le tier « Experiment » de l'API La Plateforme — source : Mistral AI Free Tier 2026 (AgentDeals, non daté, consulté 2026-09-24) https://agentdeals.dev/vendor/mistral-ai — confiance : basse — classe : stabilité (CONTRADICTION avec le changelog officiel, voir « Pistes à creuser »)
- La page tarifs mistral.ai (pricing) mentionne pour l'offre gratuite de Le Chat : « Limited messages and web searches », « Limited coding sessions » et « $10/mo in API credits » — ceci concerne l'offre consumer Le Chat, pas clairement le tier Experiment de l'API pure — source : Pricing (mistral.ai, non daté, consulté 2026-09-24) https://mistral.ai/pricing — confiance : moyenne — classe : tarif
- Le tier Experiment est unanimement décrit par les sources tierces comme réservé à l'évaluation/prototypage, non à la production — passage au tier payant nécessaire pour un usage commercial ou en production — source : Mistral AI Free Tier 2026 (AgentDeals, non daté, consulté 2026-09-24) https://agentdeals.dev/vendor/mistral-ai — confiance : basse — classe : juridique
- Aucune carte bancaire ne serait requise pour créer un compte et utiliser le tier Experiment (affirmation reprise par plusieurs agrégateurs mais non confirmée sur une page officielle consultée) — source : Mistral La Plateforme free tier (BenchLM.ai, non daté, consulté 2026-09-24) https://benchlm.ai/free-tier/mistral — confiance : basse — classe : quota

## Candidat 2 : Google AI Studio — Gemini API free tier

- La documentation officielle de facturation confirme que le free tier ne nécessite pas de carte bancaire, seulement un « projet actif ou essai gratuit » ; passer au tier payant exige de lier un compte Cloud Billing et un prépaiement minimum de 5 $ — source : Billing (Gemini API, Google AI for Developers, mis à jour 2026-09-20, consulté 2026-09-24) https://ai.google.dev/gemini-api/docs/billing — confiance : haute — classe : tarif
- Les conditions d'utilisation additionnelles de l'API Gemini stipulent explicitement : « You may use only Paid Services when making API Clients available to users in the European Economic Area, Switzerland, or the United Kingdom » — le tier gratuit (Unpaid Services) est donc interdit pour servir des utilisateurs situés dans l'EEE, en Suisse ou au Royaume-Uni — source : Gemini API Additional Terms of Service (Google AI for Developers, non daté, consulté 2026-09-24) https://ai.google.dev/gemini-api/terms — confiance : haute — classe : juridique
- Un fil du forum officiel des développeurs Google AI, intitulé « Clarification on "Only Paid Services" for EEA/CH/UK », confirme l'existence et la discussion communautaire de cette même clause des CGU — source : Clarification on "Only Paid Services" for EEA/CH/UK (Google AI Developers Forum, non daté, consulté 2026-09-24) https://discuss.ai.google.dev/t/clarification-on-only-paid-services-for-eea-ch-uk/107860 — confiance : moyenne — classe : juridique
- Sur le tier gratuit (Unpaid Services), Google utilise le contenu soumis pour « improve, and develop Google products and services » et des relecteurs humains peuvent lire, annoter et traiter les entrées/sorties API (données dissociées du compte avant relecture) ; aucun mécanisme d'opt-out n'est prévu pour le tier gratuit — source : Gemini API Additional Terms of Service (Google AI for Developers, non daté, consulté 2026-09-24) https://ai.google.dev/gemini-api/terms — confiance : haute — classe : données
- Sur le tier payant, Google n'utilise pas les prompts/réponses pour améliorer ses produits, les logs ne sont conservés que pour détecter les violations et la conformité légale, et le traitement est couvert par le Data Processing Addendum (statut de sous-traitant) — source : Gemini API Additional Terms of Service (Google AI for Developers, non daté, consulté 2026-09-24) https://ai.google.dev/gemini-api/terms — confiance : haute — classe : données
- L'endpoint compatible OpenAI a pour base_url `https://generativelanguage.googleapis.com/v1beta/openai/` (endpoint natif : `https://generativelanguage.googleapis.com/v1beta`) — source : OpenAI compatibility (Gemini API, Google AI for Developers, non daté, consulté 2026-09-24) https://ai.google.dev/gemini-api/docs/openai — confiance : moyenne — classe : compatibilité
- Le tier gratuit donnerait accès à 11 modèles avec des limites primaires de l'ordre de 15 RPM et 1500 RPD (chiffres non vérifiés sur page officielle lors de cette recherche) — source : Free Google Gemini API Key & Free Tier (freellm.net, non daté, consulté 2026-09-24) https://freellm.net/providers/google-gemini — confiance : basse — classe : quota
- La page officielle des rate limits confirme que les limites dépendent du tier d'usage et sont visibles dans Google AI Studio, et que « les modèles expérimentaux et preview ont des limites plus restreintes », mais ne détaille pas les valeurs RPM/TPM/RPD exactes par modèle dans le contenu extrait — source : Rate limits (Gemini API, Google AI for Developers, non daté, consulté 2026-09-24) https://ai.google.dev/gemini-api/docs/rate-limits — confiance : moyenne — classe : quota

## Verdicts provisoires

Le tier Experiment semble exister sans carte bancaire, mais une possible confusion entre l'offre API et l'offre Le Chat/Vibe (changement rapporté en sept. 2026) n'a pas pu être tranchée avec des sources primaires claires. Fondé sur : affirmations BenchLM.ai et AgentDeals (confiance basse), contredites par le changelog officiel (confiance haute) qui ne montre aucun changement de l'API.
- **G2 (compatibilité OpenAI + streaming)** : incertain — non vérifié dans cette recherche (budget épuisé avant de pouvoir consulter la doc API dédiée).
- **G3 (function calling natif gratuit)** : incertain — non confirmé sur une source consultée.
- **G4 (accessible France/UE)** : passe probable — aucune restriction géographique EEE/UK/Suisse trouvée pour Mistral (société française/européenne), mais non explicitement confirmé par une page CGU consultée.
- **G5 (usage formation interne autorisé)** : incertain — les sources tierces décrivent le tier comme réservé au prototypage/évaluation, pas explicitement à la production ou à un usage de formation ; aucune clause CGU officielle consultée dans cette recherche pour trancher.

### Google Gemini API — free tier
- **G1 (gratuité réelle)** : passe pour un usage hors EEE/UK/Suisse (pas de carte bancaire requise) — fondé sur Billing (ai.google.dev, haute confiance) — mais voir G4/G5.
- **G2 (compatibilité OpenAI + streaming)** : passe — base_url `https://generativelanguage.googleapis.com/v1beta/openai/` confirmé — fondé sur OpenAI compatibility (ai.google.dev, confiance moyenne). Streaming SSE non confirmé explicitement dans cette recherche.
- **G3 (function calling natif gratuit)** : incertain — le function calling est supporté par l'API Gemini en général, mais sa disponibilité spécifique sur les modèles du tier gratuit n'a pas été confirmée par une source primaire consultée.
- **G4 (accessible France/UE)** : ÉCHOUE pour le tier gratuit. Le formateur étant en France (EEE), les CGU additionnelles de l'API Gemini interdisent explicitement d'utiliser les « Unpaid Services » (tier gratuit) pour un client API mis à disposition d'utilisateurs situés dans l'EEE, en Suisse ou au Royaume-Uni. Fondé sur : Gemini API Additional Terms of Service (haute confiance), corroboré par le fil du forum officiel Google AI Developers (confiance moyenne, même clause).
- **G5 (usage formation interne autorisé)** : ÉCHOUE en pratique pour une formation projetée en France — même si l'usage est « interne », les trainees en salle sont des « users » auxquels le client API (la démo) est rendu disponible en France, ce qui active la clause « Paid Services only » citée en G4. Un usage payant (carte bancaire liée) lèverait cette restriction géographique mais alors ce n'est plus « gratuit ».

## Pistes à creuser
- Contradiction entre agrégateurs sur un changement de l'offre gratuite Mistral en septembre 2026 (API Experiment vs Le Chat/Vibe) : le changelog officiel ne corrobore pas de changement côté API, mais reste à vérifier directement sur une page produit/CGU à jour (docs.mistral.ai/deployment/laplateforme/tier a retourné une 404 lors de cette recherche — l'URL a peut-être changé).
- La page Billing de Google (« disponible dans de nombreuses régions ») et les CGU additionnelles (« Paid Services only » pour EEE/UK/Suisse) semblent en tension : la page Billing ne mentionne pas l'exclusion, alors que les CGU l'imposent explicitement. Les CGU, plus spécifiques et à valeur contractuelle, doivent primer — mais cela mérite une double vérification directe (ex. capture d'écran AI Studio depuis une IP française).
- Non vérifié : est-ce que le statut « make available to users in EEA » s'applique à une démo projetée en salle (utilisateurs = trainees regardant l'écran, pas d'accès direct à l'API) ou seulement à un service déployé où les utilisateurs finaux appellent l'API eux-mêmes. Cette distinction est cruciale et n'a pas pu être tranchée par les sources consultées.
- Quotas précis (RPM/RPD/TPM) du tier gratuit Gemini par modèle (2.5 Flash, 2.5 Pro, 2.0 Flash) non confirmés sur source officielle dans cette recherche — seule une source agrégatrice basse confiance donne 15 RPM / 1500 RPD.
- Function calling natif sur les modèles gratuits des deux candidats : non confirmé par source primaire pour l'un ou l'autre.
