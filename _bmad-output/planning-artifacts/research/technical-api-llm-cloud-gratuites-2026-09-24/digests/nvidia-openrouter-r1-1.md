# Digest — API LLM cloud gratuites : NVIDIA Build vs OpenRouter `:free` (2026-09-24)

## Candidat 1 — NVIDIA Build / API Catalog (build.nvidia.com)

- La documentation officielle ne publie pas un quota universel : les limites de débit sont propres à chaque modèle et compte, gérées via le programme NVIDIA Developer — source : API Credit & Rate Limit Increase Request for build.nvidia.com Free Tier (NVIDIA Developer Forums, non daté, consulté 2026-09-24) https://forums.developer.nvidia.com/t/api-credit-rate-limit-increase-request-for-build-nvidia-com-free-tier/382934 — confiance : haute (forum officiel NVIDIA, message de modérateur) — classe : quota
- Le palier gratuit observé est ~40 requêtes/minute, sans voie officielle d'augmentation via le forum (un modérateur indique « no official way to circumvent this rate limit or to receive a rate limit increase on that same tier ») — même source — confiance : haute — classe : quota
- Second signal indépendant convergent sur ~40 RPM et l'absence de carte bancaire à l'inscription — source : NVIDIA Build (NIM API) Without Credit Card? (yangmao.ai, non daté, consulté 2026-09-24) https://yangmao.ai/en/providers/nvidia-build/no-credit-card/ — confiance : moyenne (agrégateur, à confirmer) — classe : quota/juridique
- L'inscription exige une vérification par numéro de téléphone, et certains pays ne sont pas proposés dans la liste (ex. Turquie +90, Kazakhstan signalés) ; la France n'apparaît dans aucun signalement de blocage trouvé — source : Unable to register on build.nvidia.com – Turkey (+90) not supported (NVIDIA Developer Forums, non daté, consulté 2026-09-24) https://forums.developer.nvidia.com/t/unable-to-register-on-build-nvidia-com-turkey-90-not-supported/367723 — confiance : haute — classe : juridique/compatibilité
- Les conditions officielles « NVIDIA API Trial Terms of Service » restreignent l'usage à des « limited trial purposes only and without use of the API Service or Generated Content in production » ; un usage production nécessite une licence NVIDIA AI Enterprise — source : NVIDIA API Trial Terms of Service (PDF officiel NVIDIA, non daté, consulté 2026-09-24) https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf — confiance : haute (source primaire officielle) — classe : juridique
  - Note de lecture : le PDF a été parcouru par extraction automatique ; les clauses précises sur journalisation des prompts / entraînement et durée exacte des crédits n'ont pas pu être confirmées dans le texte extrait — à vérifier manuellement si le juridique est bloquant.
- L'endpoint est compatible OpenAI SDK (`integrate.api.nvidia.com`), clé au format `nvapi-`, sans carte bancaire requise pour obtenir la clé — source : Free LLM API (2026): NVIDIA Gives You 100+ Frontier Models for $0 (Substack, non daté, consulté 2026-09-24) https://sidsaladi.substack.com/p/free-llm-api-nvidia-nim — confiance : basse (blog non officiel, ton marketing) — classe : compatibilité
- Appel d'outils natif confirmé pour plusieurs familles hébergées sur NIM/Build : Llama 3.1/3.2/3.3, Mistral (auto), Llama Nemotron Nano/Super/Ultra (avec « detailed thinking » désactivé), Llama 3.1 70B/405B, Nemotron-3-Super, GLM 4.7/5.1, Kimi K2, Mixtral 8x22B, Qwen 2.5 72B — source : Function (Tool) Calling with NVIDIA NIM for LLMs (docs.nvidia.com, non daté, consulté 2026-09-24) https://docs.nvidia.com/nim/large-language-models/1.10.0/function-calling.html — confiance : haute (documentation produit officielle) — classe : compatibilité
- Modèles gratuits représentatifs cités par les agrégateurs : plus de 80-100 modèles hébergés (Llama, Nemotron, Mistral, Qwen, GLM, Kimi K2, Mixtral) — source : Free LLM API (2026) (Substack) et NVIDIA Build Free API: 100+ AI Models on DGX Cloud (pasqualepillitteri.it, non daté, consulté 2026-09-24) https://pasqualepillitteri.it/en/news/1621/nvidia-build-free-api-100-ai-models-2026 — confiance : basse (deux agrégateurs, recoupement faible car proviennent probablement d'une même page NVIDIA) — classe : modèles
- Aucune preuve trouvée de changement récent (12 derniers mois) du volume de crédits gratuits (1000 crédits mentionnés de façon stable dans plusieurs sources non datées) — pas de source primaire datée trouvée confirmant une évolution — classe : stabilité — confiance : basse

## Candidat 2 — OpenRouter, modèles `:free`

- Limite officielle : 20 requêtes/minute pour tous les comptes sur les modèles `:free` ; 50 requêtes/jour si moins de 10 $ de crédits achetés à vie, 1000 requêtes/jour si ≥ 10 $ achetés (le seuil reste acquis même si le solde redescend) — source : API Credit & Rate Limits — Handle 402 and 429 Errors (openrouter.ai/docs, non daté, consulté 2026-09-24) https://openrouter.ai/docs/api_reference/limits — confiance : haute (documentation officielle primaire) — classe : quota
- Le streaming (SSE) est explicitement supporté sur les variantes gratuites, aucune carte bancaire n'est requise pour un accès initial — même source — confiance : haute — classe : compatibilité/juridique
- Confirmation indépendante du chiffre de 20 RPM et d'un plafond journalier (~200/jour cité par un agrégateur récent, valeur discordante par rapport aux 50/1000 de la doc officielle — probablement un chiffre daté ou moyen) — source : OpenRouter Free Tier 2026: Rate Limits, Free Models Tested (klymentiev.com via recherche, non daté, consulté 2026-09-24) — confiance : basse — classe : quota
  - Conflit à noter : documentation officielle (50 ou 1000/jour selon crédits) vs plusieurs agrégateurs citant « 200/jour ». La doc officielle prime (source primaire, plus récente).
- Sur la confidentialité : OpenRouter ne journalise pas les prompts par défaut sur les modèles payants avec Zero Data Retention, MAIS les modèles gratuits sont explicitement décrits comme un échange : « OpenRouter offers free models in exchange for using your data to train their AI systems », avec des réglages opt-out séparés pour payant/gratuit et pour la publication des prompts — source : Provider Logging — Provider Data Retention Policies + page Privacy (openrouter.ai/docs, non daté, consulté 2026-09-24) https://openrouter.ai/docs/guides/privacy/provider-logging — confiance : haute (documentation officielle) — classe : données
- Le contrôle opt-out existe (« Enable free endpoints that may train on inputs », « …may publish prompts », désactivables) mais l'opt-out réduit alors l'accès à une partie des modèles gratuits selon plusieurs sources secondaires convergentes — source : OpenRouter Free Models: Limits, Privacy and Fallbacks Explained (llmrumors.com, non daté, consulté 2026-09-24) — confiance : moyenne — classe : données
- L'API est compatible OpenAI (base_url `https://openrouter.ai/api/v1`) — fait connu et stable, confirmé de façon cohérente par toutes les sources consultées (doc officielle citée ci-dessus, page limits) — confiance : haute — classe : compatibilité
- Instabilité documentée du catalogue gratuit : suivi communautaire GitHub montre des ajouts/retraits quasi quotidiens (« 24 current free models with 1 added and 1 removed recently » au 24/09/2026) ; des modèles autrefois populaires comme `deepseek/deepseek-r1:free` et `qwen/qwen3-coder:free` n'existent plus — source : OpenRouter free model updates (2026-09-24) (GitHub issue, dépôt cyclez2000/openrouter-free-models, publié 2026-09, consulté 2026-09-24) https://github.com/cyclez2000/openrouter-free-models/issues/76 — confiance : moyenne (tracker communautaire mais daté et vérifiable, change log réel) — classe : stabilité
- Second signal convergent sur l'instabilité : « le catalogue gratuit change très vite… peut être soudainement retiré, changer de fournisseur, être bridé, ou disparaître » — source : OpenRouter Free Models: Limits, Privacy and Fallbacks Explained (llmrumors.com) — confiance : basse (agrégateur) mais confirme le pattern du signal haute confiance ci-dessus — classe : stabilité
- Modèles gratuits représentatifs au 24/09/2026 (lecture directe de la page collection, incomplète) : « Space Bunny Alpha » (modèle stealth/anonyme, fenêtre de contexte 1M tokens, multimodal, raisonnement ajustable) et « Ming Image 0.1 Design Layer » (image-to-image, non pertinent pour du texte/outils) — source : Free AI Models on OpenRouter, collection lue via openrouter.ai/models?max_price=0 (openrouter.ai, non daté, consulté 2026-09-24) — confiance : basse (extraction automatique incomplète, la page ne s'est pas rendue entièrement ; liste probablement tronquée) — classe : modèles
  - Autres noms cités par agrégateurs mais NON vérifiés sur source primaire : Llama 4 Maverick/Scout (free), Qwen3 variantes (free), DeepSeek V3 Base — à confirmer directement sur openrouter.ai/models avant de les citer dans le livrable final.
- Aucune preuve trouvée, dans les sources consultées, que l'appel d'outils (function calling) soit garanti sur les modèles `:free` spécifiquement — la doc des limites ne mentionne pas ce point, et aucune source consultée ne liste les modèles `:free` supportant nativement `tools`/`tool_choice`. Point non tranché.

## Verdicts provisoires par critère

### NVIDIA Build
- **G1 Gratuité réelle** : incertain. Pas de carte bancaire requise (source basse confiance), crédits ~1000 mentionnés sans date de péremption confirmée sur source primaire ; vérification téléphone obligatoire avec restrictions pays non confirmées pour la France. → fondé sur : forum NVIDIA (rate limit) + yangmao.ai (carte) + forum Turquie (vérif tel).
- **G2 Compatible OpenAI + streaming** : passe (indication cohérente de compatibilité OpenAI SDK), mais confirmation streaming non vérifiée sur doc officielle dans cette recherche → confiance basse, à recreuser.
- **G3 Appel d'outils natif** : passe — nombreuses familles confirmées (Llama 3.x, Nemotron, Mistral, Qwen 2.5 72B, GLM, Kimi K2, Mixtral 8x22B) sur documentation officielle NVIDIA NIM.
- **G4 Accessible France/UE** : incertain — aucune preuve directe de blocage France trouvée, mais vérification téléphone obligatoire et restrictions par pays existent pour d'autres pays ; à vérifier explicitement pour la France.
- **G5 Usage formation interne autorisé** : échoue probablement — les Terms of Service officielles limitent explicitement à un usage « trial » hors production ; une formation interne projetée reste probablement tolérée comme « prototypage/évaluation » mais ce n'est pas garanti sans lecture juridique complète du PDF (extraction automatique incomplète).

### OpenRouter `:free`
- **G1 Gratuité réelle** : passe avec réserve — pas de carte requise, mais quota journalier faible (50/jour) sans 10 $ de crédits achetés, ce qui est sous le bas de la fourchette « quelques dizaines à ~200 requêtes » demandée pour une demi-journée ; franchir 1000/jour nécessite d'avoir acheté ≥10 $ de crédits (donc « gratuit » nuancé).
- **G2 Compatible OpenAI + streaming** : passe — confirmé sur documentation officielle (base_url standard, SSE supporté).
- **G3 Appel d'outils natif** : incertain — non documenté spécifiquement pour les modèles `:free` dans les sources consultées.
- **G4 Accessible France/UE** : passe — aucune restriction géographique identifiée dans les sources consultées (à confirmer si besoin critique).
- **G5 Usage formation interne autorisé** : incertain/à surveiller — les modèles gratuits sont explicitement échangés contre l'usage des données pour l'entraînement des fournisseurs sous-jacents sauf opt-out ; opt-out possible mais réduit l'accès à certains modèles gratuits. Pour une démo pédagogique en cabinet de conseil, cela pose un risque de confidentialité si des données sensibles transitent, à traiter par opt-out systématique.

## Pistes à creuser
- Contradiction quota journalier OpenRouter : doc officielle (50 ou 1000/jour selon 10 $ de crédits à vie) vs agrégateurs citant « 200/jour » — la doc officielle doit trancher, mais vérifier directement via `GET /api/v1/key` sur un compte réel avant de figer le budget de la démo.
- Liste de modèles gratuits OpenRouter incomplètement lue (l'extraction de `openrouter.ai/models?max_price=0` n'a montré que 2 modèles, dont un non pertinent) — relire la page `openrouter.ai/collections/free-models` directement, idéalement avec un navigateur, pour obtenir la liste réelle et à jour des 20+ modèles `:free`, avec fenêtres de contexte et support outils par modèle.
- Support du function calling sur les modèles `:free` OpenRouter non confirmé — à vérifier modèle par modèle (ex. si Llama 4 Maverick/Scout free existe encore et supporte `tools`).
- Clauses exactes du PDF NVIDIA API Trial ToS sur journalisation/entraînement des prompts et durée des crédits non extraites correctement (extraction automatique insuffisante) — nécessite une lecture manuelle du PDF téléchargé (sauvegardé localement lors de cette recherche).
- Accessibilité France spécifique pour l'inscription NVIDIA Build (vérification téléphone) non confirmée positivement — seuls des blocages pour d'autres pays (Turquie, Kazakhstan) ont été trouvés ; absence de preuve n'est pas preuve d'accès.
- Vitesse de génération (tokens/s) : aucune source fiable et datée trouvée pour NVIDIA Build ni pour OpenRouter `:free` dans le budget de cette recherche — point non traité, à creuser si la fluidité en direct pendant la formation est un critère décisif.
