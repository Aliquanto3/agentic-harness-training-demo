Règles :

  `content/i18n/{en,de}/`, champs `*_text`), jamais un libellé en dur ni un champ `*_fr` neuf.

  et `EXPERIENCE.md` (dossier `_bmad-output/planning-artifacts/ux-designs/ux-agentic-harness-training-demo-2026-09-22/`) dans leurs

  `artifact-design` (principes), `dataviz` pour le tableau et les jauges.
- **Atelier MCP** : naît directement avec les champs `*_text` et les trois langues ; point dur
  connu (messages JSON-RPC bruts non exposés par le SDK `mcp`) : hook de transport si
  possible, sinon reconstruction marquée « reconstitué » dans la page.
- Après chaque story : `ruff check`, `ruff format --check`, `pytest` en deux moitiés, tranches

  ne bloque pas la suite ; ne jamais casser une story livrée.

  pendant les tests (doublures seulement) ; Chrome fermé toute la nuit, Edge ouvert sur un seul
  onglet vide (c'est lui qui porte l'extension pour la phase 3).

  d'administrateur. `uv` pour tout, jamais `pip`.
